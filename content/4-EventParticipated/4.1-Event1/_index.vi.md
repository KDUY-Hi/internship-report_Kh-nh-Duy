# AWS Workshop và định hướng cloud

## Nội dung tham gia

- Tìm hiểu các nhóm dịch vụ AWS cốt lõi: compute, storage, database, networking, security và monitoring.
- Thảo luận cách triển khai web application trên AWS.
- Liên hệ dịch vụ AWS với project Student Internship Portal.

## Kiến thức áp dụng vào dự án

- EC2 phù hợp để chạy FastAPI backend.
- RDS PostgreSQL phù hợp để lưu dữ liệu quan hệ.
- S3 phù hợp để lưu CV và static frontend assets.
- IAM giúp cấp quyền theo nguyên tắc least privilege.
- CloudWatch hỗ trợ theo dõi log và lỗi trong quá trình vận hành.

## Kết quả

Sau hoạt động này, nhóm xác định được kiến trúc triển khai phù hợp cho project và chuẩn bị các bước thực hiện trong workshop.
