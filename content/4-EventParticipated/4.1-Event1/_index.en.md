## Activities

- Studied core AWS service groups: compute, storage, database, networking, security, and monitoring.
- Discussed how to deploy a web application on AWS.
- Connected AWS services to the Student Internship Portal project.

## Knowledge Applied to the Project

- EC2 is suitable for running the FastAPI backend.
- RDS PostgreSQL is suitable for relational business data.
- S3 is suitable for CV storage and static frontend assets.
- IAM helps apply least-privilege access control.
- CloudWatch supports log and error monitoring during operation.

## Result

After this activity, the team identified a suitable deployment architecture for the project and prepared the implementation steps for the workshop.
