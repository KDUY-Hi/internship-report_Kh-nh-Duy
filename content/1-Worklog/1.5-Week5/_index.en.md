### Goals

- Add admin features to control data quality.
- Standardize skill and job-position lists.

### Work Completed

| Task | Result |
| --- | --- |
| Admin user management | View users and lock/unlock accounts |
| Admin post approval | Approve, reject, close, or delete internship posts |
| Skill management | Add skills for filtering and input support |
| Job-position management | Standardize recruitment positions |

### Results

The system now has an approval mechanism so students only see approved internship posts. Skills and job positions were standardized to support analytics.
