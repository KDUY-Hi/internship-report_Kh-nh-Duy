### Goals

- Become familiar with the internship program and the **Application Development on AWS** direction.
- Identify the project problem: building an internship portal for students.
- Review AWS fundamentals: EC2, S3, RDS, IAM, and CloudWatch.

### Work Completed

| Task | Result |
| --- | --- |
| Analyze the needs of students, companies, and admins | Defined three main user groups |
| Study web application architecture on AWS | Selected React frontend, FastAPI backend, and PostgreSQL database |
| Initialize the project repository | Created `backend`, `frontend`, and `deploy` folders |
| Review basic AWS materials | Understood the roles of EC2, S3, RDS, IAM, and CloudWatch |

### Results

The team agreed on the project name **Cloud-based Student Internship Portal on AWS**, the feature scope, and the cloud deployment direction. This became the foundation for backend and database design in the following weeks.
