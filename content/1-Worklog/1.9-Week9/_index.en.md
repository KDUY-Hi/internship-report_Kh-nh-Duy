# Week 9 - EC2 and Backend Deployment

### Goals

- Learn how to deploy the FastAPI backend to Amazon EC2.
- Configure basic networking and security groups.

### Work Completed

| Task | Result |
| --- | --- |
| Create an EC2 instance | Prepared a Linux environment for the backend |
| Install Python, venv, and dependencies | Backend can run with Uvicorn |
| Open testing port | Temporarily allowed access through port 8000 |
| Check health endpoint | `/health` returns service status |

### Results

The backend has a clear deployment path on EC2. The team gained practical understanding of security groups, inbound rules, SSH, and running a backend service in the cloud.
