This worklog records the learning and implementation process for the **Cloud-based Student Internship Portal on AWS** project. The work is divided into two main parts:

- **Backend:** the first 3 weeks focus on requirement analysis, database design, FastAPI API development, JWT authentication, and role-based authorization.
- **AWS and deployment:** the next 5 weeks focus on cloud architecture, IAM, VPC, Security Groups, S3, EC2, RDS PostgreSQL, CloudWatch, and the frontend/backend deployment process.
